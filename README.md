### EVA — EVOAI Virtual Assistant
AI-powered chat assistant built for EVOAI, a Colombian healthcare platform.

- Vector store knowledge base with real EVOAI documentation
- Voice input (Whisper), file upload (PDFs + images), persistent memory
- PostgreSQL database with session management for 1500+ concurrent users
