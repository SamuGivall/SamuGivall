## 🤖 AI & Software Development

At **EVOAI**, I work on AI agents and software designed to support real healthcare workflows.

### Prome+ — Healthcare Billing AI
AI-assisted billing platform for Promedan, designed to support billing and auditing workflows.

- Angular frontend and NestJS/Node.js backend
- PostgreSQL persistence and Redis/BullMQ background processing
- OpenAI-powered document analysis and healthcare billing knowledge retrieval
- Role-based authentication, auditability, and production-oriented deployment
- Deployed on Windows Server infrastructure with IIS

### EVA — EVOAI Virtual Assistant
AI-powered virtual assistant built for EVOAI.

- Python and FastAPI
- OpenAI APIs and vector-store knowledge retrieval
- Persistent conversations and PostgreSQL
- File and voice interaction
- Embeddable branded chat experience
